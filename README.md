# Prime Global — Global Workforce & Business Network

This repository contains the standalone Prime Global business website.

## Publish with GitHub Pages

1. Open the repository **Settings**.
2. Select **Pages** in the left menu.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

The free GitHub Pages address will be based on the GitHub account and repository name. It does not mean the paid `primeglobal.com` domain is registered or owned.

## Site contents

- `index.html` — responsive single-page business website
- Sections for About, Opportunities, Employer Connections, Data Partnerships and Contact

The site uses early-stage, transparent wording and does not claim unverified clients, vacancies, registrations or partnerships.
